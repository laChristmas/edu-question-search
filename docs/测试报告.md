## 1. 测了什么

| 层 | 入口 | 判定 |
|---|---|---|
| 单元 / 规则 | `tests/` | 原题、变式、「不同故事不算变式」、公式门、附图、OCR 噪声 |
| 文本金标 | 把库内题干当查询 | 上界：识图完美时的命中 |
| 渲染图（部署指标） | 白底题图 → RapidOCR / PaddleOCR-VL → 检索 | 与线上一致 |

渲染图按来源分流：APE / CM17K / MATH **开公式检测**（原题 = 题干 ∧ 公式 ∧ 附图）；Geometry3K **关公式检测**（原题 = 题干 ∧ 附图，RapidOCR，不跑读题模型）。金标是题目 **id**，不是「题干字符串相同」。

| 指标 | 含义 |
|---|---|
| 命中@3 | 金标 id 出现在最多 3 条结果里 |
| 首位 | 金标排第一 |
| 标成原题 | 金标被标 `original` |
| 误标其他原题 | 结果里还有别的 `original` |
| 空结果 | 一条都不返回 |

失败类型：

| 类型 | 含义 |
|---|---|
| 空结果 | 识图后过不了门，或召回被截断成 0 |
| 未命中 | 金标不在 top-3（可能返回了别的原题/变式） |
| 命中但未标原题 | 金标在结果里，却被标成 `variant` |
| 误标其他原题 | 把近邻也当成原题 |
| 负例应拒绝 | 单元测试：不该返回的题必须不返回 |

## 2. 单元测试（规则层）

`.\.venv\Scripts\python -m pytest tests -q` → **65 passed**（2026-09-10）。

这些用例本身就是「失败形态」的对照：查询满足某条件时，系统必须拒绝原题或拒绝返回。

### 2.1 同一运算、不同故事：不得当变式返回

查询「班长把 1860 本练习册平均分给 10 个人」，不得返回「学校把 135 本练习本平均分给 3 个班」。结构分实测约 0.58，低于 `t_var=0.85`。对应 `tests/test_pipeline.py` 中的 `test_same_operation_different_story_is_not_returned`。

对照正例：只改数字「学校把 248 本练习本平均分给 4 个班」必须把 135 本那道标成 `variant`（`test_true_variant_is_returned`）。

### 2.2 公式对不上：开公式检测时不得标原题

题干叙述可以相同，查询公式模板是 `f(x)=x+NUM`，库内是对数值域题。公式门失败 → 不算原题。对应 `tests/test_filter.py` 中的 `test_formula_mismatch_blocks_original_when_formula_on`。

关掉公式检测后，同一对只比题干 ∧ 附图，应标原题（`test_without_formula_original_is_stem_and_diagram_only`）。

### 2.3 整张照片背景：不得当原题附图

两张题干不同、背景色块相似的图，不得因「整图很像」标成原题（`test_full_photo_similarity_is_not_used_as_original`）。同一题干 + 裁出的配图，即使照片有杂物，仍应命中（`test_same_stem_and_cropped_figure_match_despite_clutter`）。题干相同、附图明显不同，不得标原题（`test_same_stem_different_attached_figure_is_not_original`）。

### 2.4 其它应拒绝 / 应截断

| 用例 | 失败形态 | 期望 |
|---|---|---|
| `test_unrelated_not_variant` | 结构完全不同 | `unrelated`，不进最终 3 条 |
| `test_never_returns_more_than_three` | 召回很多 | 最多 3 条 |
| `test_cutoff_allows_empty` | 分数过低 | 允许空结果 |
| `test_math_uses_problem_not_solution` | MATH 入库误用解答 | 检索文本必须是 `problem` |

## 4. APE（中文应用题，公式开）

文本金标 1328/1328 全中。渲染图 1322/1328 命中（99.5%），空结果 5 条（0.4%），另 2 条命中但未标原题。误标其他原题为 0。

逐条 jsonl 已删，下面用题库里真实题面说明这类数据**几乎不失败**的原因，以及剩余约 6 条图搜失败最可能的形态。

**近重复但仍应能分开（本源误标其他原题为 0）：**

| id | 题干 |
|---|---|
| `1069569` | 农研所进行种子发芽试验，用 300 粒种子进行试验，其中有 15 粒种子没有发芽．求种子的发芽率． |

故事骨架接近，数量不同。字符 TF-IDF + 数量门把它们当变式而不是互标原题，这是 APE 与 CM17K 的差别。

## 5. CM17K（中文数学题，公式开）

渲染图命中@3 **92.1%**，与文本金标几乎相同（都是 92.1%），空结果约 0。失败不在识图，而在**题库近邻**：误标其他原题文本 8.1%、图搜 14.1%。

逐条 jsonl 已删。评测集里有成对的「同一故事、只改条件」条目，足以说明这类失败长什么样。

**失败形态：同一篇应用题拆成两问，结构/公式几乎一样，互相被标成 `original`。**

评测集 `cm17k-10036` 与 `cm17k-10037` 前半句完全相同（甲乙物流、A/B 相距 400 千米、C 中转、速度 120/80），只在最后一问不同：

- `cm17k-10036`：若 2 车**未相遇**，求 2 车相距 50 千米时的行驶时间。
- `cm17k-10037`：若 2 车**已经相遇**，求 2 车相距 50 千米时的行驶时间。

按产品规则这不是同一道原题（条件相反），也不是「只改数字」的变式。字符重叠极高时，题干门 + 公式门会两边都过，`cutoff` 的 `t_same=0.90` 又只比文本、不比「问句里的未/已经」。这就是 CM17K 约 1/7 图搜带「误标其他原题」的来源。

未命中的约 8% 同样是近邻占掉 top-3，金标 id 没挤进去（不是空结果）。

这是最差的一组。图搜命中@3 **41.0%**，空结果 **50.9%**；即使把金标题干直接当查询，命中也只有 **58.3%**，误标其他原题 **55.0%**。金标按 **id**，大量题干是 `Find x.`。

## 7. Hendrycks MATH（英文竞赛题，公式开）

渲染图命中@3 **85.2%**，空 **12.3%**。文本金标 98.8%，所以图搜丢掉的约 15 个百分点主要来自识图 / 公式门，不是词表。图搜失败计数：未命中 491（其中空 408），命中但未标原题 74，误标其他原题 142。

### 7.1 空结果：`[asy]` 图没画进评测 PNG

库内题干含 Asymptote 作图；评测 PNG 只渲染了文字。读题看不到图像，公式/附图门对不齐，返回空。

| 金标 id | 库内题干（节选） | 识图查询（节选） | top-3 |
|---|---|---|---|
| `math-test-algebra-106` | Below is a portion of the graph of $y=h(x)$: `[asy] import graph; ...` | 文字问了 $h(x)>x$，没有曲线 | （空） |

入库时 `[asy]...[/asy]` 会从可检索题干剥掉，查询侧又读不到图，两边都缺图则附图项通过，但题干/公式仍可能对不上。

### 7.2 空结果：天花板/地板被读成绝对值

| 金标 id | 库内公式 | 识图公式 | top-3 |
|---|---|---|---|
| `math-test-algebra-1093` | $\lceil\sqrt{10}\rceil+\lfloor\sqrt{10}\rfloor$ | $\lvert\sqrt{10}\rvert+\lvert\sqrt{10}\rvert$ | （空） |
| `math-test-algebra-240` | $\lceil\sqrt{27}\rceil-\lfloor\sqrt{26}\rfloor$ | $\lvert\sqrt{27}\rvert-\lvert\sqrt{26}\rvert$ | （空） |

一边抽到绝对值公式、一边库内是 ceil/floor，**单侧有公式则公式门失败**，精排清空。

同类：`math-test-algebra-2` 库内 $\lceil x\rceil+x=23/7$，识图变成 $\lvert x\rvert+x=23/7$，未空但金标未进 top-3，返回 `math-train-algebra-1299:variant`。

### 7.3 空结果：自定义算符或矩阵环境被读歪

| 金标 id | 库内 | 识图 | top-3 |
|---|---|---|---|
| `math-test-algebra-253` | $P\ast Q$ 定义为 $(P+Q)/2$，求 $3\ast(6\ast 8)$ | 星号变成 $\times$，与普通乘法混淆 | （空） |
| `math-test-algebra-291` | `align*` 方程组 | `aligned` 环境，公式模板对不齐 | （空） |

`math-test-algebra-1107`、`math-test-algebra-413`、`math-test-algebra-211` 识图文字已经接近金标，仍为空：一边抽出了分式/根号公式、另一边模板规范化后不相等。

### 7.4 未命中：近邻被标成原题，金标被挤出

结构（数量打成 `NUM` 后）完全一样，只改数字或多项式次数。公式模板也一样，两边都过原题门。

| 查询金标 | 金标题干 | 实际返回（被当成原题） |
|---|---|---|
| `math-test-algebra-372` | Evaluate $(x+y)(x-y)$ when $x=15$, $y=5$ | `math-test-algebra-591`：同样式子，$x=13$, $y=5$ |
| `math-test-algebra-1066` | $x^2+18x=27$，正根写成 $\sqrt{a}-b$ | `math-train-algebra-143`（结构分 1.0，公式分 1.0） |
| `math-test-algebra-745` | $\log_5(1/625)$ | 另外三道 `Evaluate $\log$` 全标 original |
| `math-test-geometry-167` | Compute $\sin 30^\circ$ | 三道别的 `Compute $\sin/\cos$` original |

文本金标同样会把 `372` 判给 `591`：这是**数量门没有挡住「同一表达式、不同代入值」**，不是 OCR。

### 7.5 命中但未标原题：基数下标被读成十进制

| 金标 id | 库内 | 识图 | 结果 |
|---|---|---|---|
| `math-test-number-theory-1` | 水管工 $242_5$ 美元/小时，$367_8$ 设备费，$3.5_{10}$ 小时 | `2425 dollars`、`3678 dollars`、`3.510 hours` | 金标标成 `variant/0.587` |
| `math-test-number-theory-109` | $324_8$ 加 $111010101110_2$ | 下标还在，进制记号与模板不完全一致 | 金标 `variant/0.548` |

`math-test-algebra-547` 等比数列求和识图几乎逐项正确，金标却排在 `math-train-algebra-193:variant` 后面，自身也是 variant：长公式模板分低于 `t_formula=0.82`。

### 7.6 误标其他原题：多项式只差次数

| 查询 | 金标 | 额外 original |
|---|---|---|
| `math-test-algebra-411` | $(x-1)\cdot f(x)=3x^4+\cdots$，求 $\deg f$ | `math-test-algebra-656`：$(x^2-1)\cdot f(x)=5x^6+\cdots$ |
| `math-test-algebra-167` | $x+1/x=7$，求 $x^2+1/x^2+1$ | `math-train-algebra-357`（同一恒等式族） |
| `math-test-algebra-26` | $(2x+5)(x-3)=14$ | `math-train-algebra-29` |

`cutoff` 只按题干表面分 ≥ 0.90 去重，不比公式次数，这两道会并排以 original 返回。

## 8. 按失败原因横切

| 原因 | 主要出现在 | 例子 |
|---|---|---|
| RapidOCR 把图注拼进短题干 | Geometry3K 图搜空结果 | `g3k-1006`：`Find x.2x+13x-1` |
| 短题干重复，金标靠 id 不靠字面 | Geometry3K 文本/图搜未命中 | 多道 `Find x.` 互标 original |
| ceil/floor → 绝对值 | MATH 图搜空 / 未命中 | `1093`、`240`、`algebra-2` |
| `[asy]` 图未进入评测 PNG | MATH 图搜空 | `algebra-106` 函数图像 |
| 自定义算符 / 进制下标 | MATH | `P * Q` 读成乘；`$242_5$` 读成 2425 |
| 同一表达式不同数字仍过原题门 | MATH 文本+图搜 | `372`（x=15）→ `591`（x=13） |
| 同一故事不同问句互标原题 | CM17K、部分 G3K | `cm17k-10036` / `10037`；`g3k-1053` / `1104` |
| 公式模板差一点，金标被标变式 | MATH | `algebra-547` 等比求和 |

## 9. 结论

- 规则层 65 个单元测试通过。负例（不同故事、公式不对、背景当附图、最多 3 条）有对应用例。
- 部署图搜总体命中@3 **86.8%**。APE 已接近饱和（99.5%）；CM17K 卡在近邻互标原题，不卡识图；MATH 约 12% 空结果来自读题（ceil、asy、进制）；Geometry3K 一半空结果、短题干撞车，是当前短板。
- 不要用文本金标 92.7% 对外宣传产品成功率。
- 逐条失败：MATH / Geometry3K 见 `data/eval/formula_10k/*/results_image.jsonl`；APE / CM17K 只保留了本节的汇总与典型题面。
